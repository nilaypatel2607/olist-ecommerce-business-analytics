# 🛒 Olist E-commerce Business Analytics Project

## 📌 Project Overview

This project focuses on analyzing Brazilian e-commerce business data to understand sales performance, customer behavior, product category performance, and delivery trends.

The objective of this project is to transform raw e-commerce data into meaningful business insights using Python and Power BI.

An interactive Power BI dashboard was developed to help understand business performance through key metrics, visualizations, and trend analysis.

## 🎯 Business Objectives

- Analyze overall sales and revenue performance.
- Understand monthly revenue trends.
- Identify top-performing product categories.
- Analyze customer purchasing behavior.
- Evaluate delivery performance.
- Identify opportunities for business improvement.

## 🛠️ Tools & Technologies

- **Python:** Data analysis and data preprocessing.
- **Jupyter Notebook:** Python-based analysis.
- **Power BI:** Interactive dashboard development.
- **Pandas:** Data manipulation and analysis.
- **Matplotlib / Seaborn:** Data visualization (if used).

## 📂 Dataset

The project uses the Brazilian E-commerce Public Dataset by Olist.

The dataset contains information related to:
- Customers
- Orders
- Order Items
- Products
- Payments
- Sellers
- Reviews
- Geolocation

## 📊 Power BI Dashboard

The interactive dashboard consists of four main sections:

### 1. Cover Page
Introduction and overview of the project.

### 2. Executive Overview
Provides an overview of business performance through:
- Delivered Revenue
- Total Orders
- Average Order Value
- Repeat Customers
- Monthly Revenue Trends
- Revenue by Product Category

### 3. Category Analysis
Focuses on product category performance and revenue contribution.

### 4. Delivery & Customers
Provides insights into customer behavior and delivery performance.

## 🔍 Key Business Insights

The analysis focuses on identifying:

- Monthly sales and revenue trends.
- Top-performing product categories.
- Customer purchasing patterns.
- Repeat customer behavior.
- Delivery performance and potential delays.
